# StudyBuddy — Project Risk Register

This document outlines the technical, architectural, integration, and operational risks identified in the project plan, along with their current mitigation status. Owner and target resolution dates are left for team coordination during sprint syncs.

---

| Risk ID | Risk Description | Category | Impact | Likelihood | Current Real Status & Technical Mitigation | Assigned Owner | Target Date |
|:---:|---|---|:---:|:---:|---|:---:|:---:|
| **R-01** | **LLM API Rate Limiting (HTTP 429) & Upstream Outages**<br/>Exceeding Gemini API quotas or upstream cloud delays causing tutor 500 errors. | Architectural / External | High | High | **MITIGATED (Member A):** Wrapped API calls in `AbortController` (15s timeout) with exactly 1 retry for 429/5xx. If retries fail, returns friendly fallback tutor response (`getFriendlyFallbackResponse`) with status 200. Zero 500s. | *[Team]* | *[Date]* |
| **R-02** | **Prompt Injection & Tool-Forcing Jailbreaks**<br/>Malicious queries attempting to override tutor instructions or execute unauthorized `create_task` calls. | Security | Critical | Medium | **MITIGATED (Member A):** 3-layer guardrail defense: (1) Normalization (stripping zero-width chars and collapsing whitespace), (2) Delimited data wrappers (`<<<STUDENT_INPUT>>>`, etc.), (3) Server-side schema validator (`toolValidator.js`) and strict `req.user.userId` binding. Model only runs tools from structured output. | *[Team]* | *[Date]* |
| **R-03** | **Teammate Integration Delays & Schema Drift**<br/>Delays in Member B's MongoDB models blocking chatbot schedule ingestion. | Team / Process | High | High | **MITIGATED (Member A):** Established `plannerRepository.js` as the single integration point. Chatbot, context builder, and tools query this layer. Currently backed by `mockPlannerStore.js`; Member B can swap in Mongoose queries without modifying chatbot code. | *[Team]* | *[Date]* |
| **R-04** | **Date & Timezone Calculation Bugs**<br/>24-hour floor/ceil math or UTC offset drift causing "exam tomorrow" to display "0 days left" or overdue. | Quality / UX | Medium | Medium | **MITIGATED (Member A):** Implemented `calculateCalendarDaysLeft` in both frontend (`dateUtils.js`) and backend (`plannerRepository.js`) comparing target date midnight to local today midnight. | *[Team]* | *[Date]* |
| **R-05** | **UI Desynchronization on Chat Tool Actions**<br/>Student asks chatbot to create or reschedule tasks, but Dashboard and Planner show stale data until page reload. | Quality / UX | Medium | High | **MITIGATED (Member A):** Chat response handler inspects `data.toolCalls` for `create_task` or `reschedule_missed`, bumps `plannerLastUpdated` timestamp, and triggers automatic background `loadTasks()` in `useStore.js`. | *[Team]* | *[Date]* |
| **R-06** | **Session Hijacking / Cross-Tenant Data Access**<br/>Passing `userId` through model function arguments allowing cross-student planner tampering. | Security | Critical | Low | **MITIGATED (Member A):** `userId` is strictly injected from authenticated token context (`req.user.userId`), completely ignoring any client or model-supplied ID parameter. | *[Team]* | *[Date]* |
| **R-07** | **Accessibility & WCAG AA Non-Compliance**<br/>Low contrast gray text on dark backgrounds or inaccessible keyboard navigation in modals. | Accessibility | Medium | Medium | **MITIGATED (Member A):** Raised text contrast to `text-slate-300` / `text-slate-400` across shell, sidebar, and chat; added ARIA labels, dialog semantics, focus retention, and Escape-to-close on `FloatingChatWidget`. | *[Team]* | *[Date]* |
| **R-08** | **Production MongoDB Connection Failure**<br/>Atlas cluster unreachable or network firewall blocks port 27017 during demo. | Infrastructure | High | Low | **OPEN FOR MEMBER B:** Server includes `getDBStatus()` check and in-memory mock fallback mode if `MONGODB_URI` is disconnected. Member B to finalize Atlas production credentials. | Member B | *[Date]* |
| **R-09** | **JWT Authentication Expiry Handling**<br/>Expired token causing unhandled 401 exceptions across app pages. | Auth / Security | Medium | Medium | **MITIGATED (Member A):** Added global 401 response interceptor in `client/src/services/api.js` that clears storage, dispatches `studybuddy:unauthorized`, and triggers `ProtectedRoute` redirection to `/login`. | *[Team]* | *[Date]* |
